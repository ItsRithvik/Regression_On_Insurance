# Regression_On_Insurance
Cleaned and visualized data about client's features and their insurance premium then used that data to train a neural network model to predict insurance premiums.

## The Data
The dataset used in this project is 200 MB and hosted directly on Kaggle.
To run this notebook locally:
1. Download the data from the Regression with an Insurance Dataset Page (https://www.kaggle.com/competitions/playground-series-s4e12).
